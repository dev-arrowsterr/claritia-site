// How it works

From a sentence to a green check.

No selectors to write and no scripts to fix. Tell Claritia what a user does, and it handles the rest.

  1. // step 01

    Describe

    Write the flow the way you'd explain it to a new teammate. Or paste your product spec.

  2. // step 02

    Run

    Claritia drives a real browser, step by step, and saves the video, screenshots and logs.

  3. // step 03

    Heal

    When your UI changes, Claritia finds the new button and asks you to approve the fix.

  4. // step 04

    Gate

    Tests run on every pull request. A failure blocks the merge and posts the video.
